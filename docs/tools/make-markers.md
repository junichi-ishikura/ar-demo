# make-markers.mjs — マーカー画像を作る

## 何をするか
デモA・B で「かざす紙」になる **マーカー画像**（1024×1024 px の PNG）を 3 枚作ります。
出力先: `assets/markers/marker-1.png` `marker-2.png` `marker-3.png`

AR の画像認識は、特徴点（角や模様の変わり目）の多い絵でないと動きません。このスクリプトは次の条件を満たすように、幾何学模様をランダムに描きます。

- 左右上下に対称でない、同じ模様の繰り返しでない
- 白と黒だけでなく、灰色の中間調も含む（背景のタイルで確保）
- 画面いっぱいに模様があり、余白が少ない
- 3 枚が互いに似ていない（シードと色テーマを変える。1 = 青、2 = 赤、3 = 緑）
- 文字（あ・る・駅・↑ など）や番号バッジで特徴点を増やしている

## 使い方
```
node tools/make-markers.mjs              # 3 枚、既定のシードで作る
node tools/make-markers.mjs 3 12345      # 3 枚、シード 12345 で作り直す
node tools/make-markers.mjs 5            # 5 枚作る（4枚目以降は色テーマが 1 から繰り返し）
```
| 引数 | 意味 | 既定値 |
|---|---|---|
| 1 つ目 | 枚数 | 3 |
| 2 つ目 | シード（乱数の種）。同じ数字なら同じ絵になる | 20260910 |

## 実行後にやること（重要）
マーカー画像を変えたら、**MindAR 用の `.mind` ファイルを作り直す**必要があります。作らないと、新しい紙をかざしても古い絵を探し続けます。

1. https://hiukim.github.io/mind-ar-js-doc/tools/compile を開く
2. 3 枚まとめてアップロード → Start
3. 緑の点（特徴点）が画像全体に散らばっていれば OK。少ない・偏っている画像があればシードを変えて作り直す
4. Download → `marker/targets.mind` として上書き保存

印刷は `print/index.html`（印刷用ページ）から。11cm 角で印刷されます。

## カスタマイズしたいとき
スクリプト冒頭の `THEMES` の色（`accent`）と `GLYPHS` の文字を変えると雰囲気を変えられます。
写真や自作イラストをマーカーにしたい場合は、このスクリプトを使わず、1024×1024 の PNG を `assets/markers/marker-1.png` などの名前で上書きし、上の手順で `.mind` を作り直してください。コンパイラの特徴点が少なければ、コントラストを上げる・細部を増やすなどの加工が必要です。

## 注意
- 生成した PNG は 1 枚 300KB 前後。トップページのサムネイルにも使っています
- 印刷は **マット紙**推奨。光沢紙は反射で認識が落ちます
